# 16BitFlash Programmer (SEGA Mega Drive / Genesis)

🌐 **Язык / Limba / Language:** [Русский](README.md) | [Română](README_RO.md) | [English](README_EN.md)

![Version](https://img.shields.io/badge/version-v4.3.0-blue)
![Platform](https://img.shields.io/badge/platform-RP2040%20%7C%20Arduino%20Nano%20%7C%20Qt%206-green)
![License](https://img.shields.io/badge/license-MIT-orange)

> 💡 **История проекта:** Проект изначально задумывался как простой эксперимент для изучения работы COM-порта, протокола UART и передачи данных между ПК и внешними устройствами, но вырос в полноценный профессиональный программатор.

Программатор на базе микроконтроллера **Raspberry Pi Pico (RP2040) или Arduino Nano**  и управляющего ПО на **Qt 6 C++** для **Чтения, Записи, Стирания, Проверка и Auto-ID:** 16-битных Flash-микросхем (серии **MX29LV, AM29LV, S29GL** и др.) и картриджей **SEGA Mega Drive / Genesis**.

---

## 🚀 Что нового в версии v4.3.0

Версия **v4.3.0** вобрала в себя весь проверенный функционал прошлых версий и получила масштабные обновления для работы с железом и гибкости настройки:

### 1. Кнопка «Chip ID» (Автоопределение чипа)
* Реализована функция автоматического определения микросхемы по её уникальным идентификаторам (MID и CID), считываемым через микроконтроллер RP2040 или Arduino.
* На главный интерфейс добавлены информационные метки (`Chip Information`), отображающие название определенного чипа, его ID и реальный объем памяти.
* При открытии файла большего размера выбор в программе допускается, но буфер и настройки автоматически урезаются до физического размера микросхемы.

### 2. Внешняя база данных микросхем (`chips.txt`)
* Добавлена поддержка внешнего конфигурационного файла **`chips.txt`**, располагающегося рядом с исполняемым файлом программы. Из него приложение автоматически считывает названия, производителей (`MID`), ID устройства (`CID`) и размеры микросхем.
* **Автосоздание шаблона:** Если файла нет, программа автоматически создаёт его со стартовым набором чипов и комментариями. Теперь можно самостоятельно добавлять новые чипы в текстовом файле без необходимости перекомпилировать исходный код программы.

### 3. Аппаратный мониторинг стирания по биту `DQ7`
* Убраны старые задержки: теперь процесс стирания поправлен по состоянию бита **`DQ7`** с визуальным миганием светодиода на плате RP2040 или Arduino.
* На стороне ПК-приложения внедрен надежный асинхронный перехват статуса готовности через сигналы с защитным таймером, благодаря чему интерфейс программы полностью отзывчив во время стирания.

Если объём совпадает со стандартным — выбирает соответствующий пресет; если нет — передаёт на микроконтроллер точный конечный адрес файла произвольного размера. * **Быстрое тестирование:** Режим `TEST 32KB` позволяет быстро проверить шину и чип без задержек.
* **Проверка дампа:** Опциональная проверка данных кнопкой `Verify` по желанию после записи.
* **Защита процессов:** Блокировка спящего режима ОС во время работы с Flash.

## 🖥 Интерфейс и возможности ПО (Qt GUI)

![Interface](interfaece.png)

* **Мониторинг:** LCD-таймер операций и окно консольного лога.
* **Карточка Chip Information:** Информационная панель на главном экране, отображающая название определенного чипа, его ID и реальный объем памяти.
* **Выбор объема / Auto ROM Select:** Пресеты от 512 KB до 32 MB, `TEST 32KB` (быстрая проверка) и смарт-режим **`Auto ROM Select`**.
* **Hex-просмотрщик:** Встроенная визуализация дампов памяти на 16 колонок (`Show buffer`).
* **Основные операции:** Чтение, Запись, Стирание, Проверка и Автоопределение микросхемы.

## 🌟 Ключевые особенности

* **Автовыбор чипа и Auto-ID:** Автоматическое определение модели и параметров микросхемы по ее уникальным идентификаторам.
* **Автоопределение объема памяти по ID:** Программа сама сопоставляет считанные MID/CID с базой `chips.txt` и выставляет корректный размер.
* **Маппер SSF2 (до 32 МБ):** Поддержка банковской коммутации для работы с крупными ROM-образами. Для этого используются специальные скетчи для RP2040 с суффиксом **`"_SSFmap"`** (предназначены **исключительно** для картриджей со встроенным маппером SSF2). При использовании стандартных скетчей без маппера для работы с объемами свыше 4 MB (8 MB и 16 MB) требуется обязательная распайка дополнительных адресных линий микросхемы **`A21/A22`**.
* **Двунаправленный Byte Swapping:** Программатор автоматически переставляет байты при чтении и записи.
* **Аппаратная интеграция:** Шина данных 16-бит через MCP23017 (I2C) / MCP23S17 (SPI), шина адреса через каскад 74HC595.
* **Скорость записи (1 МБ):** ~5 минут на Raspberry Pi Pico (против ~30 минут на Arduino Nano).
* **Защита процессов:** Блокировка спящего режима ОС во время работы с Flash и защита буфера от превышения объема микросхемы.

## 🔌 Схема подключения

### 1. Шина адреса (74HC595)
| Сигнал | RP2040 (Pico) | Arduino Nano |
| :--- | :--- | :--- |
| **SER (Data)** | GP2 | A0 |
| **L_CLK (Latch)** | GP3 | A1 |
| **S_CLK (Clock)** | GP6 | A2 |

### 2. Линии управления Flash-памятью и Индикация
| Сигнал | Слот (Pin) | RP2040 (Pico) | Arduino Nano | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **LED (W/R)** | — | GP20 | D7 | Светодиодный индикатор процесса чтения/записи |
| **#WE** | B30 | GP7 | A3 | Write Enable (LOW) |
| **#CE** | B17 | GP8 | D8 | Chip Enable (LOW) |
| **#OE** | B16 | GP9 | D9 | Output Enable (LOW) |
| **#TIME** | B31 | GP21 | D5 | Time/Peripheral chip select |
| **#LWR** | B28 | GP22 | D6 | Lower Byte Write |
| **#RST** | B27 | RUN | RESET | Линия сброса (Reset) |

### 3. Шина данных (MCP23S17 / MCP23017)

#### MCP23017 (I2C Mode)
| Сигнал MCP23017 | RP2040 (Pico) | Arduino Nano | Описание |
| :--- | :--- | :--- | :--- |
| **SDA** | GP4 | A4 | I2C Data Line |
| **SCL** | GP5 | A5 | I2C Clock Line |

#### MCP23S17 (SPI Mode — Рекомендуется)
| Сигнал MCP23S17 | RP2040 (Pico) | Arduino Nano | Описание |
| :--- | :--- | :--- | :--- |
| **CS** | GP17 | D10 | Chip Select |
| **SCK** | GP18 | D13 | SPI Clock |
| **MOSI (SI)** | GP19 | D11 | Master Out Slave In |
| **MISO (SO)** | GP16 | D12 | Master In Slave Out |

## 💾 Поддерживаемые чипы

Программа поддерживает широкий набор 16-битных параллельных Flash-памятей, включая:
* **Macronix:** MX29LV400, MX29LV800, MX29LV160, MX29LV320, MX29LV640
* **AMD / Fujitsu / Spansion:** AM29LV800, MBM29LV400/800
* **STMicroelectronics / Eon / EliteMT:** M29W160, EN29LV160/800, ES29LV800, HY29F800 и др.
* **Spansion / Cypress:** Семейство S29GL (S29GL256S, S29GL128S, S29GL064x, S29GL032x и др.)

*(Полный перечень всегда доступен для редактирования в файле `chips.txt` рядом с программой).*
