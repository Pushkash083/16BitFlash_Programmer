> 💡 **История проекта:** Проект изначально задумывался как простой эксперимент для изучения работы COM-порта, протокола UART и передачи данных между ПК и внешними устройствами, а в итоге вырос в полноценный программатор.

Программатор на базе **Arduino NANO** (или ESP8266) и **Qt 6 C++** для работы с 16-битными Flash-микросхемами (серии **MX29LV, AM29F, ES29LV, HY29F, S29AL**) и картриджами **SEGA Mega Drive / Genesis**.

---

## 🖥 Интерфейс и возможности

ПО предоставляет простой и функциональный интерфейс:

* **Мониторинг:** LCD-таймер операций и окно консольного лога.
* **Выбор объема:** Фиксированные пресеты (от 512 KB до 8 MB), `TEST 32KB` (быстрая проверка) и смарт-режим `Auto ROM Select`.
* **Hex-просмотрщик:** Встроенное окно просмотра дампа памяти на 16 колонок.
* **Основные операции:** Чтение, Запись, Стирание, Проверка.

---

## 🌟 Ключевые особенности

* **Умный Auto ROM Select:** Автоматически определяет размер файла. Если объём совпадает со стандартным — выбирает соответствующий пресет; если нет — передаёт на микроконтроллер точный конечный адрес файла произвольного размера. Для работы с объемами свыше 4 MB (8 MB и 16 MB) требуется распайка линий $A21/A22 \to A22/A23$.
* **Скорость работы:** Чтение 1 MB занимает ~3.2 мин. Из-за аппаратных ограничений Arduino Nano (16 МГц), протокола UART и I2C/SPI запись происходит медленно — ~30 мин на 1 MB.
* **Аппаратная интеграция:** Шина данных 16-бит через MCP23017 (I2C) / MCP23S17 (SPI), шина адреса через каскад 74HC595.
* **Двунаправленный Byte Swapping:** Программатор сам автоматически переставляет байты и при чтении, и при записи. Файлы `.bin`, `.gen`, `.md` сразу готовы для работы без сторонних утилит.
* **Быстрое тестирование:** Режим `TEST 32KB` позволяет быстро проверить шину и чип без задержек.
* **Проверка дампа:** Опциональная верификация данных кнопкой `Verify` по желанию после записи.
* **Защита процессов:** Блокировка спящего режима ОС во время работы с Flash.

## 🛠 Аппаратное обеспечение (Hardware)

В репозитории представлены файлы для самостоятельной сборки устройства:
* **Схема:** Принципиальная электрическая схема программатора.
* **Gerber-файлы:** Готовые файлы для заказа печатной платы (PCB) на производстве.

## 🔌 Схема подключения

### Шина адреса (74HC595)
|      Сигнал       | Arduino Nano | ESP8266 |
|       :---        |     :---     |   :---  |
| **SER (Data)**    |      A0      |    D4   |
| **L_CLK (Latch)** |      A1      |    D5   |
| **S_CLK (Clock)** |      A2      |    D3   |

### Линии управления Flash
| Сигнал  | Arduino Nano | ESP8266 |      Описание       |
|  :---   |     :---     |   :---  |        :---         |
| **#CE** |      D8      |    D0   | Chip Enable (LOW)   |
| **#OE** |      D9      |    D6   | Output Enable (LOW) |
| **#WE** |      A3      |    D7   | Write Enable (LOW)  |

### Шина данных (MCP23017 / MCP23S17)
* **SPI:** 
| (MCP23S17)    |       Arduino | 
| pin #11 (CS)  | SPI CS   (10) |
| pin #12 (SCK) | SPI SCK  (13) |
| pin #13 (SI)  | SPI MOSI (11) |
| pin #14 (SO)  | SPI MISO (12) |
* **I2C:** 
| (MCP23017)    | Arduino(ESP8266) |
| pin #12 (SCL) |  A5   (D2 ESP)   |
| pin #13 (SDA) |  A4   (D1 ESP)   |
