> 💡 **История проекта:** Проект изначально задумывался как простой эксперимент для изучения работы COM-порта, протокола UART и передачи данных между ПК и внешними устройствами, но вырос в полноценный программатор.

Программатор на базе микроконтроллеров **Raspberry Pi Pico (RP2040)**, **Arduino Nano** или **ESP8266** и управляющего ПО на **Qt 6 C++** для чтения, записи, верификации и стирания 16-битных Flash-микросхем (серии **MX29LV, AM29F, ES29LV, HY29F, S29AL, S29GL** и др.) и картриджей **SEGA Mega Drive / Genesis**.

---

## 🚀 Что нового в версии v3.0.0

* **Переход на RP2040 (Raspberry Pi Pico):** 32-битный микроконтроллер ARM Cortex-M0+.
* **Обновление ПО для ПК (Qt GUI):** В десктопное приложение добавлена полная поддержка и оптимизация протокола обмена для микроконтроллера **RP2040**.
* **Прирост скорости:** Время записи **1 МБ** сократилось с **~30 минут** (на Arduino Nano) до **~5 минут** (на RP2040). Запись огромных дампов на **15 МБ** занимает всего **~1 час 10 минут** вместо **~8 часов 20 минут** (на Arduino Nano).
* **Обновленная печатная плата (PCB v3.0.0):** Двухслойная плата с двойным посадочным местом (Pico + Nano), светодиодной индикацией операций и поддержкой быстрых расширителей **MCP23S17 (SPI)** / **MCP23017 (I2C)**.

## 🖥 Интерфейс и возможности ПО (Qt GUI)

![Interface](Interface.png)

* **Мониторинг:** LCD-таймер операций и окно консольного лога.
* **Выбор объема:** Пресеты от 512 KB до 16 MB, `TEST 32KB` (быстрая проверка) и смарт-режим `Auto ROM Select`.
* **Hex-просмотрщик:** Встроенная визуализация дампов памяти на 16 колонок (`Show buffer`).
* **Основные операции:** Чтение, Запись, Стирание, Проверка.

---

## 🌟 Ключевые особенности

* **Умный Auto ROM Select:** Автоматически определяет размер файла. Если объём совпадает со стандартным — выбирает соответствующий пресет; если нет — передаёт на микроконтроллер точный конечный адрес файла произвольного размера. Для работы с объемами свыше 4 MB (8 MB и 16 MB) требуется распайка адресных линий микросхемы памяти $A21/A22$.
* **Аппаратная интеграция:** Шина данных 16-бит через MCP23017 (I2C) / MCP23S17 (SPI), шина адреса через каскад 74HC595.
* **Двунаправленный Byte Swapping:** Программатор сам автоматически переставляет байты и при чтении, и при записи. Файлы `.bin`, `.gen`, `.md` сразу готовы для работы без сторонних утилит.
* **Быстрое тестирование:** Режим `TEST 32KB` позволяет быстро проверить часть данных и работоспособность шины.
* **Проверка дампа:** Верификация данных после записи.
* **Защита процессов:** Блокировка спящего режима ОС во время работы с Flash

## 🔌 Схема подключения

### 1. Шина адреса (74HC595)
| Сигнал | RP2040 (Pico) | Arduino Nano | ESP8266 |
| :--- | :--- | :--- | :--- |
| **SER (Data)** | GP2 | A0 | D4 |
| **L_CLK (Latch)** | GP3 | A1 | D5 |
| **S_CLK (Clock)** | GP6 | A2 | D3 |

### 2. Линии управления Flash, Индикация и Управление банков
| Сигнал | RP2040 (Pico) | Arduino Nano | ESP8266 | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **#WE** | GP7 | A3 | D7 | Write Enable (LOW) |
| **#CE** | GP8 | D8 | D0 | Chip Enable (LOW) |
| **#OE** | GP9 | D9 | D6 | Output Enable (LOW) |
| **LED (W/R)** | GP20 | D7 | D2 | Светодиодный индикатор процесса чтения/записи |
| **#TIME** | GP21 | D5 | — | Зарезервировано: управление банками |
| **#LWR** | GP22 | D6 | — | Зарезервировано: управление банками / запись RAM |

### 3. Шина данных (MCP23S17 / MCP23017)

#### MCP23017 (I2C Mode)
| Сигнал MCP23017 | RP2040 (Pico) | Arduino Nano | ESP8266 | Описание |
| :--- | :--- | :--- | :--- | :--- |
| **SDA** | GP4 | A4 | D1 | I2C Data Line |
| **SCL** | GP5 | A5 | D2 | I2C Clock Line |

#### MCP23S17 (SPI Mode — Рекомендуется для v3.0.0)
| Сигнал MCP23S17 | RP2040 (Pico) | Arduino Nano | Описание |
| :--- | :--- | :--- | :--- |
| **CS** | GP17 | D10 | Chip Select |
| **SCK** | GP18 | D13 | SPI Clock |
| **MOSI (SI)** | GP19 | D11 | Master Out Slave In |
| **MISO (SO)** | GP16 | D12 | Master In Slave Out |
