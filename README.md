> 💡 **История проекта:** Проект изначально задумывался как простой эксперимент для изучения работы COM-порта, протокола UART и передачи данных между ПК и внешними устройствами, но вырос в полноценный программатор.

Программатор на базе микроконтроллеров **Raspberry Pi Pico (RP2040)** или **Arduino Nano** и управляющего ПО на **Qt 6 C++** для **Чтение, Запись, Стирание и Проверка** 16-битных Flash-микросхем (серии **MX29LV, AM29F, ES29LV, HY29F, S29AL, S29GL** и др.) и картриджей **SEGA Mega Drive / Genesis**.

---

## 🛠️ Что нового в версии v3.1.1

* **Qt 6 GUI:** Добавлена возможность выбора и работы с образами объемом до 32 МБ в интерфейсе программы.
* **Поддержка RP2040:** Добавлены новые скетчи для Raspberry Pi Pico с поддержкой Sega Bank Switching (SSF2 Mapper).
* **Чтение и запись (SSF2):** Реализована стабильная поддержка чтения и записи ROM-образов объемом до 32 МБ через маппер SSF2 на железе без необходимости пайки (требуется картридж со встроенным маппером).

## 🚀 Версия v3.1.0

* **Обновление интерфейса ПО (Qt GUI):** Улучшен пользовательский интерфейс, оптимизировано управление размерами ROM через выпадающий список (QComboBox) и обновлено окно информационной карточки проекта.
* **Переход на RP2040 (Raspberry Pi Pico):** Полная поддержка 32-битного микроконтроллера ARM Cortex-M0+.
* **Оптимизация протокола обмена:** Десктопное приложение адаптировано и оптимизировано для работы с высокими скоростями **RP2040**.
* **Прирост скорости:** Время записи **1 МБ** составляет **~5 минут** (на RP2040) против **~30 минут** (на Arduino Nano). Запись дампов объемом **15 МБ** занимает **~1 час 10 минут** вместо **~8 часов 20 минут**.
* **Печатная плата (PCB v3.0.0):** Двухслойная плата с двойным посадочным местом (Pico + Nano), светодиодной индикацией операций и поддержкой быстрых расширителей **MCP23S17 (SPI)** / **MCP23017 (I2C)**.

## 🖥 Интерфейс и возможности ПО (Qt GUI)

![Interface](Interface.png)

* **Мониторинг:** LCD-таймер операций и окно консольного лога.
* **Выбор объема:** Пресеты от 512 KB до 32 MB, `TEST 32KB` (быстрая проверка) и смарт-режим `Auto ROM Select`.
* **Hex-просмотрщик:** Встроенная визуализация дампов памяти на 16 колонок (`Show buffer`).
* **Основные операции:** Чтение, Запись, Стирание, Проверка.

---

## 🌟 Ключевые особенности

* **Умный Auto ROM Select:** Автоматически определяет размер файла. Если объём совпадает со стандартным — выбирает соответствующий пресет, если нет — передаёт на микроконтроллер точный конечный адрес файла произвольного размера. Для работы с объемами свыше 4 MB (8 MB и 16 MB) требуется распайка адресных линий микросхемы памяти $A21/A22$.
* **Аппаратная интеграция:** Шина данных 16-бит через MCP23017 (I2C) / MCP23S17 (SPI), шина адреса через каскад 74HC595.
* **Двунаправленный Byte Swapping:** Программатор сам автоматически переставляет байты и при чтении, и при записи. Файлы `.bin`, `.gen`, `.md` сразу готовы для работы без сторонних утилит.
* **Быстрое тестирование:** Режим `TEST 32KB` позволяет быстро проверить часть данных и работоспособность шины.
* **Проверка дампа:** Проверка данных после записи.
* **Защита процессов:** Блокировка спящего режима ОС во время работы с Flash.

## 🔌 Схема подключения

### 1. Шина адреса (74HC595)
| Сигнал | RP2040 (Pico) | Arduino Nano |
| :--- | :--- | :--- |
| **SER (Data)** | GP2 | A0 |
| **L_CLK (Latch)** | GP3 | A1 |
| **S_CLK (Clock)** | GP6 | A2 |

### 2. Линии управления Flash-памятью, Индикация сигналы
| Сигнал | Слот (Pin) | RP2040 (Pico) | Arduino Nano |  Описание |
| :--- | :--- | :--- | :--- | :--- |
| **LED (W/R)** | — | GP20 | D7 |  Светодиодный индикатор процесса чтения/записи |
| **#WE** | B30 | GP7 | A3 |  Write Enable (LOW) |
| **#CE** | B17 | GP8 | D8 |  Chip Enable (LOW) |
| **#OE** | B16 | GP9 | D9 |  Output Enable (LOW) |
| **#TIME** | B31 | GP21 | D5 |  Time/Peripheral chip select|
| **#LWR** | B28 | GP22 | D6 |  Lower Byte Write|
| **#RST** | B27 | RUN | RESET |  Линия сброса (Reset) |

### 3. Шина данных (MCP23S17 / MCP23017)

#### MCP23017 (I2C Mode)
| Сигнал MCP23017 | RP2040 (Pico) | Arduino Nano |  Описание |
| :--- | :--- | :--- |  :--- |
| **SDA** | GP4 | A4 |  I2C Data Line |
| **SCL** | GP5 | A5 |  I2C Clock Line |

#### MCP23S17 (SPI Mode — Рекомендуется)
| Сигнал MCP23S17 | RP2040 (Pico) | Arduino Nano | Описание |
| :--- | :--- | :--- | :--- |
| **CS** | GP17 | D10 | Chip Select |
| **SCK** | GP18 | D13 | SPI Clock |
| **MOSI (SI)** | GP19 | D11 | Master Out Slave In |
| **MISO (SO)** | GP16 | D12 | Master In Slave Out |
